# DotStimVisual
Programming for Psychology DotStimVisual assignment

1. Task Overview:
A dot stimulus task testing participant's ability to determine predominant movement of dots

2. Task:
In each trial, participant will see a collection of moving dots and indicate whether left or right is the predominant direction.
Trials vary by direction and coherence levels.

3. Experiment output
The outputs are:
a. excel file with all trials and their direction, coherence, whether their response was correct, their response (left or right), reaction time, fixation duration.
b. A scatter plot showing reaction time by coherence level
c. A histogram of reaction time
d. A line graph of accuracy (%) by coherence level
